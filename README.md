# Focus OS

A React-based focus timer and analytics dashboard designed to support structured work sessions and lightweight self-reflection.

## Overview

Focus OS is a productivity web app that combines a Pomodoro-style timer, task tracking, and simple analytics in one workspace.

It is built for users who want not only to track focus time, but also to better understand how they work by comparing **planned time and actual time** and reviewing daily focus patterns.

## Features

- Pomodoro-style focus timer
- Task-based session tracking
- Daily focus time visualization
- Planned vs actual time comparison
- Lightweight analytics for reviewing work habits

## Tech Stack

- React
- Vite
- Recharts
- Local Storage

## Goal

This project explores how a focused workspace can support both time management and personal work analysis through a simple, visual interface.
